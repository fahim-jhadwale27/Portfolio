# Fahim — Portfolio Website

A personal portfolio website created for **Builder’s Day at Scaler School of Technology**.

The website showcases my introduction, skills, projects, learning journey, and work through a responsive dark-themed design.

## Technologies

* HTML
* Tailwind CSS

### Tailwind CSS

Tailwind CSS is included via CDN and used for utility classes in the website. The main visual design and styling are handled using custom CSS in `style.css`.

## Features

* Responsive navigation
* Hero section
* About / journey section
* Focus areas
* Skills section
* Project showcase
* Responsive design
* Hover effects and animations
* Bento-style layouts
* Smooth scrolling
* Accessible focus states
